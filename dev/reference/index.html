Reference ​

The reference covers one part of the package per page. The Julia pages carry the docstring of every symbol the package documents. The two JavaScript pages are the normative contracts the browser side implements, and both sides of the wire obey them.

The package ​

CesiumLink.CesiumLink Module
julia
CesiumLink

Drive the CesiumLink browser client from Julia over a WebSocket.

Serve the viewer with start_server, declare the ES modules it loads with register_module!, and broadcast time-varying scene data with push_window — one message per run of keyframes, carrying every module's payload for those frames.

A session can be recorded with record! and played back later with replay, which drives a real viewer through it with whatever produced the data absent.

source

Julia ​

  • The server: the listener, the module set and the viewer bundle.

  • Windows and scenes: pushing keyframes, and installing a scene.

  • Events and commands: the listener registry, the reply batch and the tooltip.

  • Primitives vocabulary: points, lines and footprints.

  • UI vocabulary: the overlay list, the floating objects and their anchors.

  • Heatmap vocabulary: a coloured field draped over a box of degrees.

  • Models vocabulary: one glTF model per entity of a node family.

  • Furniture and regions: the Core's own on-screen items, and the overlay CSS.

  • The camera: the viewpoints the server declares, and when each one applies.

  • Colours: colormaps, colour bytes and legend stops.

  • Coordinates: geodetic degrees and ECEF metres.

  • Recording: writing a session to a file, and replaying it.

  • Wire codec: the internal frame and array encoding.

JavaScript ​

  • Module API: the contract a viewer module implements.

  • Wire protocol: the contract the transport encoding obeys.
