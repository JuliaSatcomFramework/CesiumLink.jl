On this page

How-to guides ​

Each guide solves one problem and assumes you can already start a server and push a window. If you cannot, read the tutorials first. For the whole surface of a function, go to Reference. For why the system is shaped this way, go to Explanation.

Put something on the globe ​

  • Draw points, lines and areas — the three families the primitives module draws, and the array shapes they take.

  • Drape a scalar field over the globe — a grid of values as colour on the surface.

  • Put your own model on a satellite — a glTF file on an entity primitives owns, and what it costs to draw.

  • Work in map coordinates — degrees in, ECEF metres out, on the ellipsoid the session declared.

Answer the user ​

  • Show a value on hover — a hover listener that writes the tooltip for the entity under the cursor.

  • Put controls in the overlay — the caption, the colour bar, the checkbox, the dropdown, and the box that holds several.

  • Put a box on screen — a box anchored to the screen, to an entity, or to a point on the globe.

Decide what the viewer shows ​

  • Choose the on-screen furniture — which of the Core's own items are on screen, and where the buttons sit.

  • Show a scene with no clock — one keyframe, and no time controls beside it.

  • Choose what the globe is textured with — a basemap from the web or from a directory of your own tiles, and how to put satellites around the Moon.

  • Give a recording a tour — declare where the camera looks, and when it goes there.

Write JavaScript ​

  • Write a module with no build step — several files, a library from the web, or a module held as a Julia string.

Move the data ​

  • Send large arrays — what the wire carries cheaply, and what it refuses.

Deliver the data ​

  • Deliver a long mission a piece at a time — declare the whole range, send a chunk, and answer core/need with the rest.

Look at the scene ​

  • Show a scene in a VSCode tab — a live scene in an editor panel, with no forwarded port.

  • Show a scene in a notebook cell — a live scene in a KaimonSlate cell, on the socket the notebook page already holds.

Look at what happened ​

  • Record and replay a session — write the frames to a file, and drive a viewer from that file later.

  • Look at what the wire carried — read a frame, its header and its region by hand.
